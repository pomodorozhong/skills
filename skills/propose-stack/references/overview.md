# Stack overview

Read this when the user asks to see the stack, its overview, status, or where things stand ("show me the stack overview"). Find the stack as [SKILL.md](../SKILL.md) describes.

Reply by filling in [the review request template](../assets/review-request.md) with the stack's current state. Start from the saved `review.md` when there is one, but refresh anything that has changed since it was written from `gh stack view --json` and `git` (commits, check results, how far the default branch has moved, and each PR's link and state, open, queued, merged, or closed, in the **PR** column once published), and save the refreshed version over it. Fill in only what exists so far: before [step 5](build-and-review.md#5-review-request), mark the sections that come later as not yet reached rather than inventing them. Showing the overview answers no open question; end with whatever request is still open.
